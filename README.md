# Fieldnotes Kanban

A small, dependency-free Kanban board. Add, edit, search, delete, and drag tasks between columns. Tasks are saved in your browser with `localStorage`.

## Run it

Open `index.html` in a browser. No install or build step is needed.

## Publish to GitHub

In VS Code, open **Source Control**, choose **Publish to GitHub**, sign in when prompted, and follow the prompts to create a repository. Do not share your password or access token in chat.
